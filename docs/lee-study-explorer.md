# Lee 2014 study explorer

The Study explorer adds a read-only numerical view of the reconstructed Lee et al. (2014) analysis to the existing research workspace. It loads a bundled public dataset only when opened and computes in the visitor's browser. It does not call an AI model, execute visitor code, alter a manuscript, or consume the site's model allowance.

## Data and scope

- Primary article: [Lee et al., DOI 10.1038/ncomms6619](https://doi.org/10.1038/ncomms6619).
- Numerical source: supplementary data 2, distributed as `ncomms6619-s3.xlsx`, sheet `Suppl_Data2`, rows 4–7893 and columns H–T. All 7,890 regional measurements and 13 profiles are included without rounding the source values.
- Four routes reuse shared source profiles. The route grid has 26 occupied slots among 36 possible route/day combinations. It is a numerical reconstruction configuration, not the proposed validated study-design manifest.
- D16L belongs to the continued-low route. The low-withdrawal route has no day-16 sample. The final high-withdrawal label is approximate (`~30`), not a precise observation timestamp.
- Regions, profiles and encoded routes are not independent biological replicates. The independent replicate count is not established by these aggregated profiles. Bulk measurements cannot establish same-cell restoration or mechanism.

The original analysis archive was unavailable. The new reconstruction's six CSV files and `verification.json` regenerated byte for byte against its own frozen copies. This does not establish identity with the missing original archive. Its 59 displayed-report checks have 58 matches and one disclosed rounding discrepancy: the unrounded DMR_6652 withdrawal-minus-low difference is 0.056277369723000015, which rounds to **0.0563**, whereas the report gives **0.0562** after subtracting rounded endpoints. Neither the source workbooks nor the original report was edited.

## Interactions

The tolerance control selects 0.02, 0.05 or 0.10 on the methylation-fraction scale (2, 5 or 10 percentage points). A region counts as returning within tolerance when at least one selected intermediate differs from baseline by more than the tolerance and the endpoint differs by no more than it. This is a descriptive threshold classification, not an exact return.

For the two day-21 routes, the schedule control selects day 8 alone, shared days 2/5/8, or all available intermediate observations. The last option adds D16L only to continued low; the UI identifies this unmatched observation opportunity. Every calculation uses all eligible regions, not a search result or the illustrated region alone.

The source inspector shows individual regional values with workbook row and cell locators. The downloadable CSVs and verification JSON are the unchanged reconstruction outputs; they are not exports of whichever interactive settings are currently selected.

## Manual check

1. Open **Project tools → Study explorer**. Confirm the reconstruction and zero-model-call labels, source links, and discrepancy notice.
2. At tolerance **5 percentage points**, select **Day 8**: continued-low and withdrawal counts should be **524** and **665**.
3. Select the shared schedule: counts should be **737** and **831**. Select all available observations: **927** and **831**, with a visible unmatched-schedule explanation.
4. Change tolerance and inspect the recalculated counts. Inspect DMR_81 and DMR_6652 and follow their source-cell locators.
5. Download a CSV and `verification.json`. The latter must retain `all_report_values_match: false` and `original_archive_byte_identity_available: false`.
6. Switch to another workspace view and back. Existing manuscript text and author decisions should be unchanged. No generation request should appear in the network log.

## Implementation boundary

`scripts/build-lee-study.py /absolute/path/to/reconstruction/lee` regenerates the browser payload and copies the frozen downloads. It requires NumPy and openpyxl, checks the workbook and reconstruction hashes, compares all 102,570 numeric values directly against the source workbook, and verifies lossless JSON serialization. This maintenance command is not needed to run or deploy the already bundled site. `public/data/lee2014/manifest.json` is a file checksum inventory, not a study-design manifest.

`npm test` includes the browser calculation and study-view tests. The numerical checks cover the six recorded schedule results, 72 path-class counts, independently recomputed tolerance/schedule combinations, source locators, the rounding discrepancy, and refusals for incomplete datasets or unsupported arguments. The provider responses in the existing AI tests are mocked.

This release does **not** implement the proposed Gill/Lee typed tool harness, claim gate, null replay, or five-arm evaluation runner. Those remain separate work requiring the previously agreed review. Existing AI endpoints, consent, limits, and author approvals are preserved.
